### Task 1.4: Create DASHLY JWT Auth

**Implementation Steps:**
1. Generate a strong secret key and store it securely.
2. Ensure to sign JWT tokens using this secret key.
3. Set reasonable expiration times for JWTs to limit potential misuse (e.g., 1 hour).
4. Use HTTPS to ensure secure transmission of JWTs.
5. Consider implementing refresh tokens for better security and user experience.
